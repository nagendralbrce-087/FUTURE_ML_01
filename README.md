# Sales & Demand Forecasting

## Project Overview

This project predicts future sales using Machine Learning techniques. Historical sales data is analyzed and a Linear Regression model is used to forecast future demand.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Scikit-Learn

## Features

* Sales Trend Analysis
* Demand Forecasting
* Data Visualization
* Future Sales Prediction

## Methodology

1. Load sales dataset.
2. Preprocess and organize data by date.
3. Train a Linear Regression model.
4. Predict future sales values.
5. Visualize actual and forecasted sales.

## Output

The model forecasts future sales and displays the trend using graphs.
